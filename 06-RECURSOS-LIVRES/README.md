## ♿ Acessibilidade e uso offline

- Os PDFs usam fonte com boa legibilidade, contraste alto e títulos hierárquicos (navegáveis por leitor de tela).
- As ilustrações são **vetoriais** e têm descrição no texto ao lado — não dependem de cor para transmitir informação.
- **Sem internet?** Salve os PDFs no computador e use o Python instalado localmente. As atividades de lógica, algoritmos e SQL não precisam de conexão.
- **Computador compartilhado?** Use contas gratuitas e nunca salve dados pessoais de alunos no repositório.

## 🧾 Checklist antes de publicar um projeto de aluno

- [ ] Nenhum nome, foto, telefone ou e-mail real de aluno
- [ ] Nenhuma senha, chave de API ou arquivo `.env`
- [ ] Licença e créditos no README do projeto
- [ ] Autorização do responsável quando houver publicação de trabalho de menor
- [ ] Links testados (sem 404)
