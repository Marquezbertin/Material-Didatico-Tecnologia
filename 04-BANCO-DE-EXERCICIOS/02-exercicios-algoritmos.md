## 🎯 Objetivo

Ao final da atividade, o aluno será capaz de:

1. Reconhecer que um **algoritmo** é uma sequência de passos com ordem definida.
2. Representar a lógica em **fluxograma** (símbolos de início/fim, processo, decisão) e em
   **pseudocódigo**.
3. Aplicar **decomposição** (quebrar o problema) e **reconhecimento de padrões** (repetição).
4. **Depurar**: encontrar e corrigir o erro em um trecho de código ou pseudocódigo.

**Objetivo secundário:** usar o caderno como "régua" de lógica — escrever o passo a passo antes
de codar, para não pular etapas.

### Exercício 16 — o programa não para ⭐⭐ · ⏱️ 4 min

```
contador ← 0
enquanto contador < 10
   escreva("Número: ", contador)
fimEnquanto
```

**O que você esperava ver?** O programa deveria imprimir os números de 0 a 9 e terminar.
**O que acontece?** O programa fica repetindo a mesma linha para sempre.

|---|---|---|
| 1 | **B** | Primeiro se **coleta** o dado, depois se **calcula**, depois se **decide** e por último se **mostra**. |
| 2 | **B** | Algoritmo é sequência finita e sem ambiguidade de passos que resolve um problema. |
| 3 | **C** | Sem o valor pago não há como calcular a diferença; a entrega vem no fim. |

| 9 | **`b`** | Se `a > b` é falso, então `b` é o maior (ou os dois são iguais). |

### Resposta do item 8 — fluxograma passo a passo

1. **Início** (elipse).
2. **Ler senha** (paralelogramo de entrada).
3. **Decisão**: `senha = "1234"?` (losango) — **Sim** vai para o passo 4, **Não** vai para o passo 5.
4. **Exibir mensagem**: no caminho "Sim" → `"Acesso negado"`.
5. **Exibir mensagem** e depois **Fim** (elipse): no caminho "Não" → `"Bem-vindo"`.

> A sequência aceita é **Início → Ler senha → Decisão → Exibir mensagem → Fim**, com o texto
> "Acesso negado" no caminho "Sim" e "Bem-vindo" no caminho "Não". O detalhe que o professor
> deve cobrar: **os dois caminhos precisam terminar** — é o erro mais comum em fluxograma de
> senha.

### Resposta do item 11 — pseudocódigo do maior de três números

```
algoritmo "maior_tres"
   var a, b, c, maior: inteiro
   inicio
   leia(a)
   leia(b)
   leia(c)
   maior ← a
   se b > maior entao
      maior ← b
   fimse
   se c > maior entao
      maior ← c
   fimse
   escreva("O maior é: ", maior)
fimalgoritmo
```

### Resposta do item 12 — classificação corrigida

```
se media >= 7 entao
   escreva("Aprovado com mérito")
senao
   se media >= 5 entao
      escreva("Recuperação")
   senao
      escreva("Reprovado")
   fimse
fimse
```

## ✅ Gabarito comentado — Bloco E (decomposição do código errado)

### Exercício 16 — o programa não para

**Erro encontrado:** falta **incrementar** a variável de controle dentro do laço. Como
`contador` continua valendo 0, a condição `contador < 10` nunca fica falsa e o programa entra
em **laço infinito**.

**Versão corrigida:**

```
contador ← 0
enquanto contador < 10
   escreva("Número: ", contador)
   contador ← contador + 1
fimEnquanto
```

**Dica para o professor:** pergunte "qual é a **condição de parada**?" — toda repetição precisa
de um contador, um sentinela ou um fim de lista.

### Exercício 17 — a porta está invertida

**Erro encontrado:** a **condição está invertida**. O código libera a entrada para quem tem
18 anos ou mais e bloqueia quem é menor — exatamente ao contrário da regra.

**Versão corrigida:**

```
leia(idade)
se idade >= 18 entao
   escreva("Entrada proibida")
senao
   escreva("Pode entrar")
fimse
```

**Alternativa equivalente (mais legível):** trocar a comparação para `se idade < 18 entao
escreva("Entrada proibida") senao escreva("Pode entrar") fimse`.

**Dica para o professor:** peça que o aluno **leia o enunciado em voz alta** e confirme que o
código faz o contrário do texto.

### Exercício 18 — a média não fecha

**Erro encontrado:** o divisor está **errado**. O programa soma três notas, mas divide por 2
em vez de 3 — por isso o resultado é 12 em vez de 8.

**Versão corrigida:**

```
nota1 ← 8
nota2 ← 6
nota3 ← 10
media ← (nota1 + nota2 + nota3) / 3
escreva("Média: ", media)
```

**Dica para o professor:** "quantos valores foram somados? então por quantos eu divido?"
Regra prática: **conte antes de dividir**.
