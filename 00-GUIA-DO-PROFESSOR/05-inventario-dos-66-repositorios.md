## 🔗 Como clonar tudo de uma vez

```bash
# Um repositório
git clone https://github.com/Marquezbertin/pensamento_computacional.git

# Todos os repositórios da sua conta (via API do GitHub)
curl -s "https://api.github.com/users/Marquezbertin/repos?per_page=100" \
  | grep -o '"clone_url": "[^"]*"' | cut -d'"' -f4 | \
  while read url; do git clone --depth 1 "$url"; done
```

**Sugestão para a turma:** cada aluno cria o **seu próprio** repositório de aulas
(a partir do `git-github-iniciantes/02_primeiro_repositorio/`) e versiona tudo.
Isso transforma o curso inteiro em **portfólio público**.
