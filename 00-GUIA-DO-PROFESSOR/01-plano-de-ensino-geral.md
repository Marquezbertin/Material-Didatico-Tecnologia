# 📐 Plano de Ensino Geral

Material de referência para planejar turmas de **crianças (8–12)**, **adolescentes (13–17)**
e **adultos/estudantes (18+)**.

> Fonte: `docs/plano-pedagogico.md` do repositório
> [`laboratorio-tech-social`](https://github.com/Marquezbertin/laboratorio-tech-social),
> combinado com o conteúdo real dos demais repositórios.

---

## 1. Os três públicos

### Exploradores (8–12 anos)
**Objetivos (do plano pedagógico):**
- Compreender o que é um computador e como ele pensa (lógica).
- Criar animações e jogos simples.
- Montar circuitos básicos e entender sensores.
- Publicar uma página web própria.

**Objetivos adicionais (do material `site/trilhas/criancas/07-informatica.html`):**
- Digitação com posição correta (dedos da "casa").
- Criar um documento simples (processador de texto).
- Criar uma planilha com fórmula `SOMA` e gráfico.
- Buscar informação e verificar se é verdadeira (leitura lateral, teste CRAAP).
- Não compartilhar dados pessoais.

**Aula típica:** 60 min. Em 8 anos o foco é **descompor**, não digitar.
Formatos que funcionam: papel, lápis, quadro, jogos de tabuleiro, leitura em voz alta.

---

### Makers/Devs (13–20 anos)
**Objetivos (do plano pedagógico):**
- Programar em Python com confiança.
- Construir sites e pequenas aplicações web.
- Aplicar noções de testes de software (QA) e qualidade.
- Analisar dados e contar histórias com números.
- Conceber e entregar um projeto de impacto social em open source.

**Objetivos adicionais (do material `site/trilhas/adolescentes/08-informatica.html`):**
- Digitação produtiva com atalhos (`Ctrl+C`, `Ctrl+V`, `Ctrl+Z`).
- Word essencial: estilos H1/H2, listas, imagens, cabeçalho/rodapé, exportar PDF.
- Excel essencial: `=SOMA()`, `=MEDIA()`, gerar gráfico.
- Pesquisa: palavras-chave, aspas, `site:gov.br`, comparar abas.
- Mídias: busca reversa de imagem, *confirmation bias*, *engagement bias*, direitos autorais.

**Aula típica:** 90 min. Aqui já se programa, versiona, testa e publica.

---

### Profissionais/Adultos (18+) — trilha do `03-JOVENS-E-ADULTOS-18+/`
Não está no plano pedagógico original (que cobre até 20 anos). Construída a partir dos
repositórios `manual-qa-completo`, `qa-automation-framework`, `art-of-software-testing`,
`agente_qaIA`, `formacaoScrumMaster`, `_framework_Scrum`, `saucedemo_robot`,
`katalon_automatizacao`, `tdm-app`, `listadetarefas_qualityAssurance`, `Analise-de-Dados`,
`central-de-noticias`, `anyms`, `esporte-sao-pedro`, `hubias-estudos`.

**Objetivos:**
- Consolidar fundamentos e ir a nível profissional em QA, automação e IA aplicada.
- Usar casos reais dos seus próprios repositórios como laboratório.

## 3. Estrutura de uma aula padrão (60–90 min)

Baseado no ciclo do plano pedagógico: **Apresentação → Exploração → Mão na massa → Projeto → Mostra**.

| Fase | Min (60) | Min (90) | O que fazer |
|---|---|---|---|
| **1. Abertura** | 5 | 8 | Recapitular a aula anterior em 1 pergunta. Apresentar o problema do dia. |
| **2. Exploração** | 10 | 15 | Conceito novo com exemplo concreto e analogia do mundo real. |
| **3. Mão na massa** | 25 | 35 | Exercício guiado, feita junto. Professor circula e ajuda. |
| **4. Projeto / Desafio** | 15 | 25 | Desafio individual ou em dupla, do repositório do aluno. |
| **5. Mostra de resultados** | 5 | 7 | 2 ou 3 alunos apresentam. Professor fecha com o que aprendeu. |

**Regra de ouro do seu repositório:** *nenhum computador obrigatório* nas primeiras aulas de crianças
(o `modulo-01-pensamento-computacional.md` diz: "60 min · Sem computador obrigatório
(dá para fazer no papel!)").

## 5. Pré-requisitos e Ferramentas

### Crianças (8–12)
- **Não precisa de computador** nas aulas 01–03.
- Precisa de: papel, lápis, quadro, 1 computador por turma (opcional), fita colorida.
- Ferramentas: Scratch (grátis), Lightbot (grátis), o próprio site `laboratorio-tech-social/site`.

### Adolescentes (13–17)
- Computador com Windows/Linux/macOS.
- Python 3.10+ (`python-do-zero` pré-requisitos).
- Navegador moderno + VS Code (`html-css-js-pratica` pré-requisitos).
- Git instalado + conta GitHub (`git-github-iniciantes` pré-requisitos).
- SQLite instalado (`banco-de-dados-sql` módulo 02 ensina).
- Conta gratuita em ferramenta de IA (`ia-para-iniciantes` pré-requisitos).

### Adultos (18+)
- Python 3.10+, Playwright (`playwright install chromium`), `requests`, `jsonschema`
  (todos do `manual-qa-completo/README.PT-BR.md`).
- `pip install -r requirements.txt` do `qa-automation-framework`.

## 7. O que NÃO fazer (armadilhas detectadas nos repositórios)

A auditoria dos repositórios encontrou divergências entre README e código. Use os repositórios
**em sala com cuidado** e não prometa o que o código não faz:

| Repositório | O que o README promete | O que o código faz |
|---|---|---|
| `instagram-dio-master` | "HTML5, CSS3 e JavaScript", botão Entrar funcional | Só HTML+CSS. `index.html` tem 49 linhas e **nenhum `<script>`**. Todos os links são `href="#"` |
| `pixelfocus` | 11 sistemas desktop para nichos | Nenhum dos 11 sistemas existe no repositório. É só página de marketing |
| `projetoscriativos` | "arquivo zipado" | O artefato real é `Imobiliaria.rar` (RAR, 5,7 MB). Não há código-fonte |
| `o_acolito` | comando de execução | O README aponta um nome de arquivo que não existe; PIL e matplotlib não estão declarados |
| `Roteiro-de-Estudos` | botão "reiniciar" e arquivo de teste | Não existem no código |
| `planilhaeletronicas` | 10 testes automatizados | **8 dos 10 falham**; 5 por rota inexistente. A doc. manda rodar `test_app.py` mas o arquivo é `casosdeteste.py` |
| `_framework_Scrum` | "completar o framework Scrum" | Só tem uma imagem e um README. Não há backlog, roles, events ou artefatos |
| `berbearia`, `Academia`, `bem-estar` | "sites de exemplo" | São sites estáticos de demonstração, bons para aula de HTML/CSS real, mas não têm lógica |
| `o-despertar-qa` | site com ferramentas interativas | As 19 páginas Wix são stubs de 333 bytes. O conteúdo real está no site publicado |

**Regra de ouro:** se você vai mostrar um projeto em aula, **abra o código na frente da turma**
e diga o que ele realmente faz. Isso é, em si, uma aula de ética e de pensamento crítico
— e conecta direto com `pensamento_computacional/15_etica_sociedade`.
